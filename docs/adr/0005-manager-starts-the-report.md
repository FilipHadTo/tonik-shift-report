# The Closing Manager starts the Shift Report; it no longer opens on the first Capture

Supersedes ADR-0002. The Closing Manager starts tonight's Shift Report at the start of the shift (around 20:00), like creating a document, and invites staff from it. One report per venue per Night; the Night is still the date the shift started, with Captures before 08:00 counting toward the previous Night. We dropped "the first Capture opens the report" because it only paid off in a real product (no empty page at 3am, no create step), while in the demo it costs a waiting state, an auto-create path and the question of where a Staff Member's Capture goes before any report exists. A started report with nothing in it is the onboarding: its empty states explain how the app works. The demo has no report list or "New report" screen; it starts on tonight's report, and auto-starting the report is a story to tell, not to build.
